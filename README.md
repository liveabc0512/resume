# 王昭穎 (Chao-Ying Wang) - 個人簡歷與自我介紹網頁

本專案為專為外商公司 HR 打造的極簡風格個人簡歷網頁。網頁結合 **30秒 HR 速覽模式**、**雙語與專業證照亮點**、**精煉版履歷歷程時間軸** 以及 **互動式自傳頁籤**。

## 🌟 網頁核心特色
- ⚡ **30 秒 HR 速覽模式**：一鍵高亮外語溝通、SOP 流程優化、跨部門協調與緊急應變核心優勢。
- 🌐 **雙語與專業證照矩陣**：突顯中原應外系學歷、TOEIC 770、JLPT N2 與丙級國貿業務技術士。
- 🎯 **精煉版歷程時間軸**：收錄政大教務處、龍巖、北科大宿舍/計畫助理、承理法律事務所與誠品星巴克等經歷。
- 📖 **互動式自傳頁籤**：4 大章節清晰展現職涯脈絡與核心價值。
- 🖨️ **一鍵列印 / 另存 PDF**：專屬 `@media print` 乾淨列印排版。

## 📁 專案檔案結構
- `index.html` - 主 HTML 結構與語意標籤
- `styles.css` - 現代化 Vanilla CSS (深淺色模式、Glassmorphism、RWD)
- `script.js` - 互動邏輯 (HR速覽切換、深淺色切換、自傳頁籤、複製 Email)
